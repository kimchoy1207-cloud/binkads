# ADR-002 스팸 정책 위반 기능 제외

원안의 다음 기능은 구현하지 않는다: 주거용 프록시+봇 브라우저로 검색결과를 클릭해 CTR/체류시간을 조작하는 M8,
PBN·만료도메인 301 링크망, 안티디텍트 브라우저로 운영하는 Web2.0 계정, 캡차 우회, Indexing API 의 비대상 페이지 남용.
이유: Google 스팸 정책 위반으로 수동 조치/디인덱스 위험이 크고, 클릭 조작은 광고·검색 사기에 해당한다.
대체: M7 은 백링크 모니터링·아웃리치 관리, M8 은 GSC 실데이터 기반 title/description 개선, M6 은 사이트맵/Search Console.
