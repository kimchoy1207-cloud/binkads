Bink Ads Ops — Mac 토큰 설치 가이드
=====================================

중요
----
- 토큰 원문은 이 ZIP에 포함되어 있지 않습니다.
- 담당자가 별도의 안전한 채널로 전달한 사용자용 설치 토큰을 사용하세요.
- 토큰을 메신저 단체방, 이메일 제목, 문서, 스크린샷에 남기지 마세요.
- 설치기는 토큰을 macOS Keychain에만 저장합니다. Claude 설정 JSON과 스킬 파일에는 저장하지 않습니다.

1. 설치 전 확인
--------------
Mac의 터미널에서 아래 명령을 각각 실행하세요.

  claude --version
  node --version
  security help

필수 조건:
- Claude Code CLI가 설치되어 있어야 합니다.
- Node.js는 v20 이상이어야 합니다.
- macOS Keychain을 사용할 수 있어야 합니다.

2. 토큰 받기
------------
담당자는 Windows에서 다음 명령으로 사용자용 토큰을 Clipboard에 복사합니다.

  cd C:\Users\ert93\Desktop\binkads
  .\Copy-Bink-Mcp-Install-Token.ps1 -Recipient User

담당자는 Clipboard의 토큰을 고객 한 명에게 안전한 1:1 채널로 전달합니다. 대표용 토큰과 사용자용 토큰을 서로 바꾸어 전달하지 마세요. 토큰을 받은 고객은 설치 입력창에 한 번만 붙여넣습니다.

3. 원클릭 설치
--------------
1) bink-ads-ops-client-mac-v1.5.0.zip의 압축을 풉니다.
2) Install-Bink-Ads-Ops-Client.command를 더블클릭합니다.
3) macOS가 차단하면 Finder에서 파일을 Control-클릭(또는 오른쪽 클릭)한 뒤 “열기”를 선택합니다.
4) “전달받은 Bink 설치 토큰을 입력하세요:”가 나타나면 토큰을 붙여넣고 Enter를 누릅니다.
   - 입력 중 문자가 화면에 표시되지 않는 것이 정상입니다.
5) “설치가 완료됐습니다”가 표시되면 Enter로 창을 닫습니다.
6) 실행 중인 Claude Code를 완전히 종료한 뒤 다시 실행합니다.

설치 위치와 저장 방식
---------------------
- Keychain service: bink-ads-os-public-api
- Keychain account: 현재 macOS 사용자 이름
- 토큰 조회는 MCP 실행 시 Keychain에서만 이루어집니다.
- 토큰은 ZIP, Claude JSON, 셸 프로필, 스킬 파일에 기록되지 않습니다.

4. 설치 확인
------------
Claude Code에서 Bink 스킬을 사용해 아래 도구를 순서대로 호출하세요.

  health_check
  list_ad_accounts
  get_outcome_performance

정상 기준:
- health_check가 성공합니다.
- MAIN 계정 827779358990481이 표시됩니다.
- REFERENCE_ONLY 계정 466362559472823, 214138318005614가 표시됩니다.

5. 토큰을 잘못 입력했거나 교체할 때
----------------------------------
터미널에서 기존 토큰을 삭제한 뒤 설치 파일을 다시 실행하세요.

  security delete-generic-password -a "$(id -un)" -s "bink-ads-os-public-api"

그 다음 Install-Bink-Ads-Ops-Client.command를 다시 열고 새 토큰을 입력합니다.

6. 설치 여부만 확인할 때
-----------------------
아래 명령은 토큰 원문을 출력하지 않고 Keychain 항목의 존재 여부만 확인합니다.

  security find-generic-password -a "$(id -un)" -s "bink-ads-os-public-api" >/dev/null && echo "토큰 설치됨" || echo "토큰 없음"

주의: 명령 끝에 -w를 붙이면 토큰 원문이 출력되므로 점검할 때는 사용하지 마세요.

7. 제거
-------
토큰만 제거하려면:

  security delete-generic-password -a "$(id -un)" -s "bink-ads-os-public-api"

토큰 제거 후 MCP 연결은 인증에 실패합니다. 폐기 또는 회전이 필요한 경우 담당자에게 사용자용 토큰 폐기를 요청하세요.

문제 해결
---------
- “Claude Code CLI가 필요합니다”: Claude Code CLI 설치 후 다시 실행합니다.
- “Node.js 20 이상이 필요합니다”: Node.js 20 이상으로 업데이트합니다.
- “설치 토큰 형식이 올바르지 않습니다/너무 짧습니다”: 공백이나 줄바꿈 없이 전달받은 토큰만 다시 붙여넣습니다.
- 인증 오류(401): 기존 Keychain 토큰을 삭제하고 담당자가 새로 전달한 사용자용 토큰으로 재설치합니다.
- 토큰을 분실하거나 노출했다고 의심되면 재사용하지 말고 담당자에게 즉시 폐기·재발급을 요청합니다.

보안 원칙
---------
- 실제 토큰 값을 화면에 출력하거나 로그에 남기지 않습니다.
- 토큰 원문을 ZIP에 추가하지 않습니다.
- AWS 주소와 인증 토큰을 Claude 설정 파일에 직접 입력하지 않습니다.
- 고객별 사용자 토큰만 설치하며, 대표용 토큰은 대표자 장비 외에는 설치하지 않습니다.
